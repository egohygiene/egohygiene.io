# Compact organization Intelligence overview

Refs [website #27](https://github.com/egohygiene/egohygiene.io/issues/27),
[organization #27](https://github.com/egohygiene/.github/issues/27) and
[acceptance #41](https://github.com/egohygiene/.github/issues/41).

The overview previously opened a large graph, repeated every endpoint as a full
card, and exposed detailed publication navigation before the visitor chose a
question. It now leads with the independently sourced review views, keeps empty
Now/directory states brief, and groups the eighteen endpoints into four compact
question areas. View scope, publication route lists, source bindings and the
relationship map use native disclosures. Available evidence and unavailable
inputs retain explicit text labels.

Repository filters, selected-repository evidence, module anchors, publication
links and graph URL selection retain their existing meanings. Locale-aware
internal links keep the shared locale behavior. A shared graph URL reopens the
map after hydration. Native disclosures, links and the graph text directory work
without JavaScript. The Now preview shows at most three items per lane and keeps
its existing full repository-context drilldown and explicit truncation text.

The narrow layout uses intrinsic wrapping, bounded badges and fluid grids.
Sanity/Audits input availability remains separate from findings, execution,
freshness or human approval. Their original source frame is labeled **Source
snapshot as of**, independently of the fleet freshness-evaluation clock.

## Remaining delivery and acceptance

The actual selected Core input has no repository directory. The brief row links
[organization #42](https://github.com/egohygiene/.github/issues/42); this UI does
not convert review components or a catalog roster into captured Core evidence.
An independent reviewed directory input is a separate producer/consumer slice.

Source integration, actual hosted export, native consumer review, reviewed
replacement selection, publication and canonical HTTPS/browser verification
remain subsequent steps. The previous live publication and recovery capture
retain their original source identities. Parent website #27 / org #27 / org #41 remain
open for their broader canaries, privacy/failure, full accessibility, restore and
human acceptance. No source model, route contract, ownership, CSP, dependency,
commerce state or publisher is changed.

Decision impact: no new ADR. This implements the progressive-disclosure behavior
already specified by the owning issues using the existing static compositor,
shared theme/locale contracts and proposed portable-export boundary. It does not
ratify that boundary or alter deployment ownership.
