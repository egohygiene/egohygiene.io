## Admission and ownership

The [checked-in capsule](../../contracts/organization-intelligence/directory/README.md)
retains the exact accepted directory/schema, stdlib-only native projector,
original source inventory and two public evidence packets. Before rendering,
the consumer checks every digest and regular/no-symlink boundary, runs only that
reviewed projector with `--check`, then matches every name/provider ID against
the existing pinned Hygiene public catalog. Rejection is isolated and exposes
no rejected metadata. A narrower authorized public selection is applied before
browser serialization. No provider discovery or general schema engine is added.

Navigation uses its own presentation field. It never populates Core repository
rows, marks a module healthy, infers freshness or promotes human assessment.
Source declarations, catalog observations and publication records retain their
original clocks. Search/link-state filters use the URL; native disclosures expose
all rows and source evidence without JavaScript.

The accepted `.github` source/payload hashes and catalog/inventory observations
render in directory provenance. Existing sealed HTML/JS hashes bind that exact
provenance and the navigation rows. The manifest public scope includes the
admitted navigation identities, while its three model slots retain their prior
identities. The format, route inventory, CSP, pins and publisher are unchanged.
